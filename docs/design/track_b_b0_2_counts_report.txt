Changes
  Updated the four pre-existing uncommitted files: count script, tests,
  mutations JSON, and this report. Raw structural definitions/readers and
  existing tests are retained. No commit or push was made.
  After counting, counts 1-9 and effective sizes on nonempty sets below
  ten are replaced by "<10". Positive effective sizes below ten are also
  suppressed conservatively even on larger sets. Zero counts and empty-set
  effective sizes remain zero. Complementary person suppression also hides
  that set's effective sizes, which could otherwise reveal its count.
  Complementary suppression repeats to a fixed point. Exact rational
  elimination also checks recovery from combined equations; it chooses
  one smallest relevant published cell before recomputing that closure.
  The public payload has only suppressed counts, plus a disclosure block
  with threshold, rule, primary cell count, each complementary pass's cell
  count, and the complementary total. It contains no private unit sets,
  unsuppressed copy, or local path.
  Default public destination: docs/design/track_b_b0_2_counts.json.
  Required --local-copy supplies an external evidence-folder destination
  for unsuppressed JSON. Repository-local paths (including symlink aliases)
  are refused before input resolution. Relative external paths work.
  Both files use exclusive creation, refusing existing files and dangling
  symlinks. If the local path appears during reading, its bytes survive
  and the newly reserved empty public file is removed.

Encoded total/parts and duplicate-cell relations
  Every output count is registered as a private set of its counting units.
  Exact incidence identities encode all additive relations among these
  cells; unit sets and coefficients are never written to either output.
  Explicit table registrations cover:
  - Overall versus eight age bands for R_FULL, R_B2, R_TA_PROXY,
    R2006_FULL, D2006, and outside-B2. A sum partition is recorded only
    when parts cover the total without overlap. This applies to persons,
    households, strata and composite design clusters; missing ages do not
    create an assumed exhaustive partition.
  - R_FULL overall households = R_B2 overall households + outside-B2
    overall households, at the 2011 anchor. Persons are not assumed to
    have that partition: non-B2 co-residents can occupy B2 households.
  - B3 pooled distinct persons versus the union of wave counts for each
    older band, together with lag intersections. Overlaps use exact
    inclusion/exclusion identities, never an assumed sum across waves.
  - Roster/subset overlaps, accuracy-positive subsets of valid rows,
    both lag sets, origin/later D2006 support, and later B2-household
    counts. No unreported remainder count is added to the output.
  - B3 valid_rows = persons; R_B2 older-band unit counts = B3 2011;
    D2006 older-band unit counts = B3 2007; D2006 support at 2009 and
    2011 = the respective 2007-origin lag-2 and lag-4 person counts.
  Household identities include collection wave, and design clusters
  include stratum. Distinct unit unions may overlap. Effective sizes
  are not added across cells, and differing weight definitions remain
  separate.
