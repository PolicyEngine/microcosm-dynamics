# INVENTED DATA - NOT A COMPARISON

The exercise-2 adapter composes the frozen Track U reproduction with
G1 attributes, G2 lifetime measures and G3 group tabulation. Its synthetic
fixtures and refusal checks live in `tests/group_breakdowns/`.

Bulky invented outcome JSON is excluded from this repository. The orphaned
sidecar for the previously removed JSON has also been removed. No real-data
pipeline or new group outcome was run during integration.

The Report earnings measure now requires all 41 ages from 22 through 62.
Incomplete histories remain unavailable; sparse-history averages are named
sensitivities. Exact race, education, labor-force and own/shared quintile
row labels are retained. Education and labor-force definitions, and
quintile population/order/ties, await registration rather than inferred
assignments. See `docs/design/lifetime_measures.md` for cleared-extract
citations and builder defaults.
